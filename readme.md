# Data Structures and Algorithms

[Romanian](readme-ro.md)

Course materials for students who are new to data structures and algorithms.
Basic programming knowledge is enough to start.

The course uses questions, diagrams, and small examples to help you:

- Understand how programs store data.
- Follow an algorithm step by step.
- Compare time and memory costs.
- Choose a data structure for a problem.

## Repository contents

- [slides/](slides/): student slides in English, with C examples in `slides/examples/`.
- [slides-ro/](slides-ro/): student slides in Romanian, with C examples in `slides-ro/examples/`.
- [labs/](labs/): lab tasks and practice exercises in English.

## How to use the materials

1. Open a slide file on GitHub to see the formatted text and Mermaid diagrams.
2. Read the lessons in number order.
3. Try each question before you scroll to the answer.
4. Follow the examples and use the source links for more detail.

To run a C example, download or clone the repository. Run the commands in the
slides from the repository's root folder. You need a C compiler.
