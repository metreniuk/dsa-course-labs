# Lab 1: Arrays

## Get started with LeetCode

1. Create a free [LeetCode account](https://leetcode.com/accounts/signup/).
2. Sign in and open a problem from the list below.
3. Read the task, examples, and constraints. Select a programming language.
4. Write your solution. Use **Run** to test it with examples and your own inputs.
5. Use **Submit** to check it against the full test set. Fix errors and submit
   again until the result is **Accepted**.
