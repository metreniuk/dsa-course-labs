# Lab 2: Linked Lists

## Implement a stack and a queue in C

Do this task locally, without LeetCode. Use a linked list for each structure.

- Stack: implement `push`, `pop`, `peek`, and `is_empty`. Use LIFO order:
  the last value added is the first value removed.
- Queue: implement `enqueue`, `dequeue`, `front`, and `is_empty`. Use FIFO order:
  the first value added is the first value removed.
- Handle removal and inspection when the structure is empty.
- Free removed nodes and all remaining nodes before the program exits.
- Test an empty structure, one value, and several values. Remove all values,
  then add a value again.
- Add `4`, `7`, and `2` in that order. Check that the stack removes
  `2`, `7`, `4`, and the queue removes `4`, `7`, `2`.
